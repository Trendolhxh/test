# 精力详情页

## 是什么
首页「今日精力」点击后的二级详情页（日 / 周 / 月 三视图），展示精力值的归因拆解——用户一目了然"我今天精力高/低，到底是哪个因素拉的"。

## 给谁解决什么
**用户**：已养成看精力值习惯的手表用户，想知道"为什么今天只有 72"或"为什么今天精力不错"。

**痛点**：首页只展示精力总分 + 三大因子加减分，不能进一步下钻。用户想知道睡眠 +85 里面到底哪些维度好、哪些差，目前无入口。

## 怎么解决

**主流程**：

```mermaid
flowchart LR
  A[首页精力卡] --> B[进入详情页]
  B --> C[日视图：归因拆解]
  C --> D[切换周/月视图]
  D --> E[柱状图 + 选中日归因]
```

---

### 精力计算模型

| 因子 | 取值范围 | 说明 |
|------|---------|------|
| 昨夜睡眠 | (0, 100] | 综合评分 |
| 小睡 | [0, 30] | 加分项 |
| 运动 | [-20, 20] | 适量加分、过量扣分 |

**总分** = 睡眠 + 小睡 + 运动，上限 100。

**睡眠分 5 个子维度**（无量化得分，仅偏差 + 评价）：

| 子维度 | 偏差示例 | 评价档位 |
|--------|---------|---------|
| 睡眠时长 | 7h 02m | 充足 / 不足 / 过多 |
| 睡眠债 | 0h / 1.2h | 无 / 轻度 / 中度 |
| 静息心率 | 52 bpm | 最佳 / 偏高 / 偏低 |
| 睡眠效率 | 92% | 最佳 / 良好 / 一般 |
| 睡眠一致性 | 提前 32 min | 最佳 / 良好 / 一般 |

---

### Layout · 日视图

顶部结构与现有二级页一致：左上返回 ← / 标题"精力" / 日·周·月 tab / 日期切换箭头。

**① 顶部主指标**
- 大字号精力值（如 `92`）+ 评价标签（如「精力充沛」）
- 评价档位：≥85 精力充沛 / 60-84 状态尚可 / <60 需要恢复

**② 归因列表（Contributors）**

参照 OURA Readiness 的 Contributors 结构，纵向列表，每行一个因子：

```
昨夜睡眠          +85    最佳 >
  ├ 睡眠时长       7h 02m      充足 >
  ├ 睡眠债         0h          无 >
  ├ 静息心率       52 bpm      最佳 >
  ├ 睡眠效率       92%         最佳 >
  └ 睡眠一致性     提前32min   良好 >
小睡              +8          >
运动              -15         >
```

- **睡眠**行：左侧因子名 + 右侧加分值 + 评价文字 + `>`（可展开子维度）
- **睡眠子维度**：展开后嵌套显示，左侧子维度名 + 右侧实际值 + 评价 + `>`（点击跳对应二级页）
- **小睡 / 运动**行：左侧因子名 + 右侧加减分值 + `>`（点击跳对应详情/记录）

**交互**：
- 睡眠行默认折叠，点击展开 5 个子维度
- 子维度行点击 `>` 跳转到对应的已有二级页（如睡眠一致性详情页）
- 小睡行点击跳转小睡记录
- 运动行点击跳转运动记录

---

### Layout · 周 / 月视图

顶部与日视图一致（tab 切换 + 日期区间行）。

**① 柱状图区域**
- X 轴：周视图 7 天 / 月视图 28-31 天
- Y 轴：精力值 0-100
- 柱体颜色按评价档位着色（充沛 / 尚可 / 需恢复 三档色）
- 默认选中今日，选中柱高亮 + 顶部显示对应日期

**② 选中日归因**
- 柱状图下方展示选中日的归因列表，结构与日视图 ② 完全一致
- 点击柱体切换选中日，归因区跟随刷新

---

### 边界与兜底

| 场景 | 处理 |
|------|------|
| 无睡眠数据（未戴表 / 首日） | 精力值不显示，归因区显示「暂无数据，请佩戴手表入睡」 |
| 有睡眠无小睡 | 小睡行显示 +0 |
| 有睡眠无运动 | 运动行显示 0（不显示正负号） |
| 未来日期 | 不可选 |
