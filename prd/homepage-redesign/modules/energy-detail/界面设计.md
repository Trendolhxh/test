# 高能时长展开 · `energy-detail` · UI PRD

## 1. 一句话

看完首屏的"今日高能时长"总数后，用户在这里看到整天 24 小时精力的起伏、此刻自己在哪一段、过去每一段伴随着什么事。

## 2. 用户什么时候用它

延续 [主文档 §L1](../../主文档.md) 的两个核心场景，再加一个回顾场景——三个场景共用同一页面，只是滚动位置和事件密度不同。

| 场景 | 用户带着的问题 | 从本页带走的答案 |
|---|---|---|
| 晨起看完首屏主数字 | "我最佳的几个小时落在哪里？" | 一眼看到 24h 曲线的凸峰时段 |
| 日间感觉状态下滑 | "我现在是真到低谷了吗？下一段高能什么时候来？" | 此刻线落在曲线的具体位置 · 下一个凸起的起点 |
| 回顾今天 / 过去某日 | "我哪段精力好 / 不好？那时我在做什么？" | 曲线 × 事件铺底的一日全景 |

**页面不回答"为什么"**——归因能力由 Agent 对话承担（v1 未做，待立项）。本页只答"是什么 / 在哪里 / 伴随什么"。

## 3. 页面基本性格

用 3 条双向度量维度定位本页的调性。各维度上的位置继承 [主文档 §L3](../../主文档.md) 的"冷静 / 正面 / 渐进披露"三约束，向 Apple HIG 的 Clarity / Deference / Depth 对齐。每条配一对具体的 Do / Don't，保证设计师能据此判对错。

### 3.1 克制 ←━━━━━●━━━━━━━━━→ 丰富 · 强偏克制

**单一视觉主角 = 曲线**。事件是前景注脚、此刻是位置标签，都不抢焦点。覆盖视觉 + 动效两面：v1 背景留白（不加节律分档色 / 时段药丸 / 装饰动效），除此刻线每分钟瞬切外全页静止。

- **Do**：曲线描边全页最粗；背景中性；事件 icon 与此刻圆点饱和度低于曲线主色。
- **Don't**：分档色块铺底压曲线；事件 icon 做动态脉冲；hero 气场渐变色延续到本页背景。

### 3.2 陈述 ←━━━━━●━━━━━━━━━→ 叙事 · 强偏陈述

只呈现事实（曲线 / 事件 / 时间），不代言感受、不做因果归因、不给行动建议。"为什么 / 该怎么做"都归 Agent 对话（v1 未做）。

- **Do**：事件文案动宾客观如 `跑步 33 min`；此刻线只标 `{HH:MM}`；空态用 `—`。
- **Don't**：`你可能感到疲惫`（代言感受）/ `因为午睡所以下午延长`（因果断言）/ `建议把会挪到下午`（行动指挥）。

### 3.3 只读 ←━━━━━●━━━━━━━━━→ 可操作 · 强偏只读

v1 是信息呈现页，非录入 / 编辑 / 操作台。唯一常规交互是切日期（前 / 后导航，不含未来）。事件点击在 Agent 对话模块上线后开放为"跳 Agent 对话"，**v1 事件不可点**。what-if 沙盘与 Agent 协商排程留给 v2。

- **Do**：曲线 / 此刻线随手指垂直滚动；前一日 / 后一日按钮可点。
- **Don't**：长按事件修改 / 删除；拖动曲线修改预测；在页上新增事件。

## 4. 常规状态（今日 · 有数据）

### 4.1 核心元素

| 元素 | 内容 | 位置 |
|---|---|---|
| 顶部锚 | `今日高能时长 7h 29min`（= hero 同值，**不可点击**——语境标签不承担跳转） | 页面顶部 |
| 主曲线 | 24h 连续预测值，凸起量 = 精力高低；**此刻前实 / 此刻后淡** | 页面主体，垂直方向（上=00:00 / 下=24:00） |
| 事件前景 | v1 共 5 类事件 icon：`sleep` / `nap` / `exercise` / `walking` / `common`（最后一类为非前 4 类的通用兜底）+ 起止时间条（瞬时事件为点，有时长事件为条） | **硬约束**：① 事件在时间轴上严格对齐其 `start_at` / `end_at`（视觉位置误差 ≤ 5 分钟）；② 事件不得遮挡曲线峰值坐标。槽位形态（左侧专属槽 / 曲线叠加 / 时间轴色带 / 其他）交设计择一。 |
| 此刻指示 | 圆点 + 横向连接线 + `{HH:MM}`，落在曲线当前时间坐标上 | 曲线上"此刻"位置 |
| 日期切换入口 | 前一日 / 后一日（未来日禁用） | 顶部区域 |

### 4.2 核心交互

| 动作 | 结果 |
|---|---|
| 从 hero 日间主数字点击 | 进入本页，默认锚定到当前时间点（此刻所在时间坐标） |
| 垂直滚动 | 查看 24h 任意时段；此刻线随曲线位移 |
| 点「前一日 / 后一日」 | 切到历史日；顶部锚 + 曲线 + 事件整组替换 |
| 返回首页 | 回 hero（交互形态交设计——PRD 不规定是顶部按钮、手势还是其他形式） |

**不做 / 待启用**：

- **点事件**：**v1 事件不可点击**。事件点击的最终行为是跳转 Agent 对话（追问归因 / 建议），而 Agent 对话模块 v1 未做。Agent 对话就绪后，本页事件统一开放为"点击跳 Agent 对话"——不在本页就地展开任何内容。
- **就地展开曲线 / 事件详情卡 / 事件弹窗**：v1 均不做。**"曲线展开"这个动作路径只发生在"从 hero 主数字进入本页"这一处**；本页内部不再承载二次展开。
- **缩放 / 时间轴双指收放 / 长按事件**：v1 不做。

## 5. 其他状态

| 状态 | 触发 | 视觉要点 | 顶部锚 |
|---|---|---|---|
| **历史日 · 有数据** | 用户切到过去某日 | 曲线全段实（无实/淡分段）· 无此刻线 · 默认锚定首事件居中 | `{date}高能时长 {Xh Ymin}` |
| **今日 · 空数据** | 授权未开 / 未累积足够数据 | 曲线位灰色占位 | `今日高能时长 —` |
| **历史日 · 无记录** | 所选日期早于本机数据起点 | 曲线位灰色占位 + `该日期无记录` | `{date}无记录` |
| **加载中** | 首次打开 / 主动刷新 / 切日期 | 曲线位 skeleton · 顶部数字位 skeleton | `今日高能时长 …` |
| **曲线失败** | 曲线请求失败 | 全页错误态 + `数据加载失败 · 点击重试` | 灰色占位 |
| **仅事件失败** | 曲线就绪但事件流失败 | 曲线正常绘制 · **曲线下方一行灰字** `事件加载失败 · 点击重试`（不占事件位、不抢曲线焦点） | 正常文案 |

**事件缺席不加文字标识**——无论触发路径是"今日空数据 / 历史日无事件 / 今日有曲线但暂无事件（如凌晨）"，画面上都只是没有事件 icon / 条，不加 `今日暂无事件` 之类文案；这种缺席本身就是信息。

**状态切换不变量**：切日期时默认锚定回 §4.2 规则。事件失败不升级为全页错误——曲线是能量表达的本体，事件是前景注脚。

## 6. 具体文案

### 6.1 顶部锚

| 主态 | 文案 | 示例 |
|---|---|---|
| 今日 · 有数据 | `今日高能时长 {energy_total}` | `今日高能时长 7h 29min` |
| 历史 · 有数据 | `{date}高能时长 {energy_total}` | `4月20日高能时长 6h 42min` |
| 今日 · 空数据 | `今日高能时长 —` | `今日高能时长 —` |
| 历史 · 无记录 | `{date}无记录` | `4月10日无记录` |
| 加载中 | `今日高能时长 …` | `今日高能时长 …` |

### 6.2 日期切换入口

| 位置 | 文案 |
|---|---|
| 前一日按钮 | `前一日`（到达下限时禁用） |
| 后一日按钮 | `后一日`（今日时禁用——不可切未来） |
| 日期选择面板标题（若走 picker 形态） | `选择日期` |

### 6.3 异常 / 空态

| 触发 | 文案 |
|---|---|
| 历史日无记录 | `该日期无记录` |
| 曲线加载失败 | `数据加载失败 · 点击重试` |
| 事件加载失败 | `事件加载失败 · 点击重试` |

> **无"今日暂无事件"文案**——事件信息缺席时，画面上就是曲线下没有事件点 / 条，不做文字标识（避免冗余；不代言"今天什么都没发生"）。

### 6.4 变量规范

| 变量 | 来源 | 格式 |
|---|---|---|
| `{date}` | 页面状态 `viewState.date` | UI：今日 `今日`；同年内 `M月D日`；跨年 `YYYY年M月D日`（契约格式 `YYYY-MM-DD`） |
| `{HH:MM}` | 端侧本地时间（此刻）/ 外部契约「高能时长曲线」预测点 | 24 小时制，两位数补零（`09:05`） |
| `{energy_total}` | 外部契约「高能时长计算」当日累计值，与 hero 主数字同源同值 | `Xh Ymin`（小时无 0 前导；不足 1h 显 `Ymin`；空 / 错误 `—`） |
| `{display_name}` | [shared/事件数据.md](../../shared/事件数据.md) `event.display_name` | 直接展示，不加引号 |
| `{event_icon}` | 事件图标 token，v1 共 5 类（见 [shared/事件数据.md §4 Event icon 映射](../../shared/事件数据.md)） | `sleep`（夜间睡眠）/ `nap`（小睡）/ `exercise`（运动，合并 moderate + vigorous）/ `walking`（走路）/ `common`（常规事件，非前 4 类的通用兜底） |
| `{phase}` | [shared/节律时段.md](../../shared/节律时段.md) | **v1 UI 不消费**，变量保留仅供后续版本接入 |
