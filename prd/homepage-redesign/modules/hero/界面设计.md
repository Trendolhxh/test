# 核心指标区 · `hero` · UI PRD

## 1. 一句话

用户打开 App 的第一眼——日间看到「今天头脑清晰了多久」，夜间看到「身体离入睡还有多远」。

## 2. 用户什么时候用它

延续 [主文档 §L1](../../主文档.md)，本模块覆盖三个核心打开场景——同一 Hero 在三个场景下都成立，只有状态行文案随时段 / 事件 / 模式切换。

| 场景 | 用户带着的问题 | 从本模块带走的答案 |
|---|---|---|
| 晨起打开 | "今天状态怎么样？" | 今日清晰时长总数 + 当前所处时段提示 |
| 日间感觉下滑 | "我现在是真到低谷了吗？下一段高能什么时候来？" | 当前时段 + 下一段起止（状态行 T3 曲线式） |
| 临睡前打开 | "我身体准备好入睡了吗？" | 入睡准备度百分比 + 当前放松阶段 |

**本模块不回答**："为什么今天是这个数字"归二级页 `energy-detail` / `event-attribution`；"我应该做什么"归 Agent 对话（v1 未做）；"一天时段分布怎样"归 `energy-detail`。

## 3. 页面基本性格

对齐 [主文档 §L3 / §L4](../../主文档.md) 与 Apple HIG 的 Clarity / Deference / Depth——以下位置是硬约束，不在本节新造偏离。

### 3.1 冷静 ←━━━━━━━━━━●━━━→ 活泼 · 强偏冷静

无装饰、无图标点缀、无渐变色块。主数字与状态行以排版说话，不靠对比色或动效抢注意力。

### 3.2 克制 ←━━━━━━━━━━●━━━→ 丰富 · 强偏克制

首屏只答"是什么 + 现在怎样"两件事。主数字是唯一主角，状态行是唯一动态元素；不加信号灯 / 心率 / 归因条 / 聊天入口。

### 3.3 陈述 ←━━━━━━━━●━━━━━→ 叙事 · 强偏陈述

只呈现事实。**不代言感受**（不写"你可能感到疲惫"）、**不做因果断言**（不写"因为昨晚睡得好所以今天清醒"）、**不给行动建议**（不写"建议把会议挪到下午"）——这三类归 Agent 对话。

### 3.4 静态 ←━━━●━━━━━━━━━→ 动态 · 偏静态

主数字、副标题、分档全天稳定。只有状态行随时段 / 事件切换，且切换**仅允许文字瞬切或短时淡入淡出**；禁跑马灯 / 滚动 / 弹跳 / 闪烁。

### 3.5 当前 ←━━━●━━━━━━━━━→ 历史 · 强偏当前

只呈现"今日此刻"。历史曲线 / 过去某日总览归 `energy-detail`；Hero 不承载任何日期切换入口。

## 4. 常规状态

描述"打开 App 有数据"这一默认态。日 / 夜双模式共享同一套元素与交互，只在主数字单位与文案上分叉（具体文案见 §6）。

### 4.1 核心元素

| 元素 | 日间内容 | 夜间内容 | 位置 |
|---|---|---|---|
| 主数字 | `7h 29min`（时长 · 小时无 0 前导 · 不足 1h 只显 `Ymin` · 空 / 失败显 `—`） | `82%`（整数百分比 · 无小数点 · 空 / 失败显 `—`） | Hero 视觉主角 |
| 副标题 | `今日头脑清晰时长` | `入睡准备度` | 主数字下方 · 固定文案 |
| 分档 | 4 档：`低` / `一般` / `良好` / `卓越` | 4 档：`身体仍活跃` / `正在放松` / `已进入放松` / `身体急需休息` | 与主数字同组 |
| 状态行 | T1 / T2 / T3 / E 四时序切换（见 §6.3） | T1 / T2 / T3 / E 四时序切换（见 §6.3） | 分档下方 · 独立一行 |
| 手动切换入口 | 用户在 Hero 区域**水平横划** | 用户在 Hero 区域**水平横划** | 不设独立按钮 / 文字链接；手势触发 |

### 4.2 核心交互

| 动作 | 结果 |
|---|---|
| 点日间主数字 | 进入二级页 `energy-detail`（曲线 / 时段 / 总量） |
| 点夜间主数字 | 无反应（v1 不下钻 · 不呈现可点击 affordance） |
| 点状态行（仅异常态下） | 重试同步；状态行切 `同步 Apple Health 数据…`，主数字回 skeleton |
| 在 Hero 区域水平横划 | 切换日 / 夜模式——Hero 区域渐隐渐现；event-attribution 事件卡片同步联动；本次有效，下次打开按 §5 的自动规则重新判定 |

**不做**：Hero 内就地展开曲线 / 事件详情 / 归因卡片；数字长按编辑；数字下拉刷新的专属动画（交给系统下拉刷新）；Hero 内嵌 Agent 聊天入口。

## 5. 其他状态

| 状态 | 触发 | 视觉要点 | 状态行文案（§6.3） |
|---|---|---|---|
| 日 → 夜 · 自动切换 | `now ≥ 推荐入睡时间 - 3h` | 主数字 / 副标题 / 分档 / 状态行 / 切换入口**同组齐换** | 切到夜间对应态 |
| 夜 → 日 · 自动切换 | 夜间睡眠事件 `just_completed` | 同上 | 切到日间对应态 |
| 空数据 | HealthKit 无数据 / 授权未开 | 数字位灰色占位 · 分档不显示 | `Apple Health 数据未更新` |
| 同步中 | 首次打开 / 下拉刷新 | 数字位 skeleton · 分档不显示 | `同步 Apple Health 数据…` |
| 计算中 | 同步完但指标未算完 | 数字位 skeleton · 分档不显示 | 日 `高能时长计算中…` / 夜 `入睡准备度计算中…` |
| 同步失败 | 后端 / 网络失败 | 数字位灰色 · 分档不显示 | `数据同步失败 · 点击重试` |

**本模块不适用的状态**：历史日 · 不适用（Hero 只呈现"今日"，历史归 `energy-detail`）；局部失败 · 不适用（Hero 数据源单一，失败即全失败）。

**状态切换不变量**：

- **一次只有一处动**——数字 skeleton 时状态行不刷新；状态行切换时数字静止；模式切换时"同组齐换"一次到位。
- **子态优先级**（状态行命中即停）：T1 进行时 > T2 完成时 > E 异常 > T3 曲线式。

## 6. 具体文案

所有文本均为成品文案，设计可直接使用。`{变量}` 规范见 §6.4。**状态行通用规则**：单行 ≤ 20 字（详见 [shared/文案长度.md](../../shared/文案长度.md)），超出末尾省略号 `…`；**严禁重复事件卡片的 duration / impact / headline 信息**。

### 6.1 固定元素（日 / 夜分叉）

见 §4.1 表格的"日间内容 / 夜间内容"两列——主数字单位、副标题、分档命名均为成品。

### 6.2 手动切换入口

无文案——手势触发，无独立按钮 / 文字链接。用户横划 Hero 区域即可在日 / 夜之间切换；切换动效为 Hero 区域渐隐渐现。

### 6.3 状态行文案库（v4 终稿）

#### T1 · 进行时

| 事件 | 文案 |
|---|---|
| 夜间睡眠 `in_progress` | `夜间睡眠中` |
| 午睡 `in_progress` | `午睡中` |
| 运动 `in_progress`（所有子类） | `{display_name}中` · 例 `跑步中` / `HIIT 中` / `骑行中` |

#### T2 · 完成时（按距结束时长渐进）

| 距结束 | 夜间睡眠 | 午睡 | 运动 |
|---|---|---|---|
| ≤ 2 分钟 | `刚刚起床` | `刚完成午睡` | `刚完成{display_name}` |
| 3–59 分钟 | `{N}分钟前醒来` | `{N}分钟前午睡结束` | `{N}分钟前完成{display_name}` |
| 1–3 小时 | `{N}小时前醒来` | `{N}小时前午睡结束` | `{N}小时前完成{display_name}` |
| > 3 小时 | 自动退场至 T3 | 自动退场至 T3 | 自动退场至 T3 |

#### T3 · 曲线式

**日间（5 条）**

| 形态 | 文案 |
|---|---|
| 高能区 · 持平 | `高能期中，约 {HH:MM} 进入过渡` |
| 高能区 · 上升 | `进入上升期，约 {HH:MM} 见顶` |
| 非高能 · 下降 | `已过高能期，约 {HH:MM} 休整` |
| 非高能 · 上升 | `过渡期中，约 {HH:MM} 进入高能` |
| 一日末尾 | `今日高能已累积完` |

**夜间（4 条，按入睡准备度分档）**

| 分档 | 文案 |
|---|---|
| < 50% · 身体仍活跃 | `身体仍活跃，约 {HH:MM} 进入放松` |
| 50–79% · 正在放松 | `正在放松，约 {HH:MM} 达到入睡` |
| 80–99% · 已进入放松 | `已进入放松，继续保持更佳` |
| = 100% · 身体急需休息 | `身体急需休息，建议入睡` |

#### E · 异常态（见 §5 触发）

| 触发 | 日间 | 夜间 |
|---|---|---|
| 数据空 | `Apple Health 数据未更新` | `Apple Health 数据未更新` |
| 同步中 | `同步 Apple Health 数据…` | `同步 Apple Health 数据…` |
| 计算中 | `高能时长计算中…` | `入睡准备度计算中…` |
| 同步失败 | `数据同步失败 · 点击重试` | `数据同步失败 · 点击重试` |

### 6.4 变量规范

| 变量 | 来源 | 格式 |
|---|---|---|
| `{display_name}` | [shared/事件数据.md](../../shared/事件数据.md) `event.display_name` | 直接展示，不加引号 |
| `{N}` | `now - event.end_at` 的整数部分 | 3–59 → 分钟；1–3 → 小时；0–2 分钟 → 落到"刚刚"档位 |
| `{HH:MM}` | 外部契约「高能时长计算」/「入睡准备度计算」预测点 | 24 小时制，两位数补零（`09:05`）；契约未返回预测点时降级 → 见 §7 |
