## 1. 定位

首屏最顶部的「总览承载区」——一眼判断今日高能 / 入睡状态。

- **承担**：主数字、分档、状态行、下钻入口。
- **不承担**：曲线 / 事件列表 / 时段分布（分别归 `event-attribution` 和 `energy-detail`）。
- **日 / 夜双模式**：日间 = 高能时长（时长单位）/ 夜间 = 入睡准备度（百分比单位），按"推荐入睡时间 - 3h"自动切换 + 支持首页手动切换（详见 §5）。
- **遵循硬约束**：[§L3 首屏一眼 / 正面框架 / 渐进披露](../../主文档.md) · [§L4 Do/Don't](../../主文档.md) · [§L8 模块切分 + 外部契约](../../主文档.md)。

### 2.C 切换瞬间（动作态）

| # | 切换 | 触发 | 视觉感受 |

### 完备性声明

- 默认 / 有数据 / 空 / 加载 / 错误五种：**日/夜各有一整套**，无"不适用"项。
- 状态行四子态：B1 / B2 / B3 + A 异常文案兜底的"E"，完备。
- 无未处理的状态转移空洞。

## 3. 内容清单

### 3.1 固定元素

| 元素 | 日间 | 夜间 |

| 分档 4 档 | `低` / `一般` / `良好` / `卓越` | `身体仍活跃` / `正在放松` / `已进入放松` / `身体急需休息` |

### 3.2 手动切换入口文案

| 当前模式 | 入口文案 |
|---|---|
| 日间 | `切换到入睡准备度` |

### 3.3 状态行文案库（v4 终稿）

**通用规则**：单行 ≤ 15 字，超出末尾省略；`{HH:MM}` 来自外部「高能时长计算」/「入睡准备度计算」契约的预测值；**严禁重复事件卡片的 duration / impact / headline 信息**。

#### 3.3.1 T1 · 进行时

| 事件 | 文案 |
|---|---|
| 夜间睡眠 `in_progress` | `夜间睡眠中` |
| 午睡 `in_progress` | `午睡中` |
| 运动 `in_progress`（所有子类） | `{display_name}中` · 例：`跑步中` / `HIIT 中` / `骑行中` / `游泳中` |

#### 3.3.2 T2 · 完成时（按距事件结束时长渐进）

| 距结束 | 夜间睡眠 | 午睡 | 运动 |
|---|---|---|---|
| ≤ 2 分钟 | `刚刚起床` | `刚完成午睡` | `刚完成{display_name}` |
| 3–59 分钟 | `{N}分钟前醒来` | `{N}分钟前午睡结束` | `{N}分钟前完成{display_name}` |
| 1–3 小时 | `{N}小时前醒来` | `{N}小时前午睡结束` | `{N}小时前完成{display_name}` |
| > 3 小时 | 自动退场至 T3 | 自动退场至 T3 | 自动退场至 T3 |

#### 3.3.3 T3 · 日间曲线式（5 条）

| 曲线形态 | 文案 |
|---|---|
| 高能区 · 持平 | `高能期中，约 {HH:MM} 进入过渡` |
| 高能区 · 上升 | `进入上升期，约 {HH:MM} 见顶` |
| 非高能 · 下降 | `已过高能期，约 {HH:MM} 休整` |
| 非高能 · 上升 | `过渡期中，约 {HH:MM} 进入高能` |
| 一日末尾 | `今日高能已累积完` |

#### 3.3.4 T3 · 夜间曲线式（4 条，按入睡准备度分档）

| 分档 | 文案 |
|---|---|
| < 50% · 身体仍活跃 | `身体仍活跃，约 {HH:MM} 进入放松` |
| 50–79% · 正在放松 | `正在放松，约 {HH:MM} 达到入睡` |
| 80–99% · 已进入放松 | `已进入放松，继续保持更佳` |
| = 100% · 身体急需休息 | `身体急需休息，建议入睡` |

#### 3.3.5 E · 异常态

| 触发 | 日间文案 | 夜间文案 |
|---|---|---|
| 数据空 | `Apple Health 数据未更新` | `Apple Health 数据未更新` |
| 同步中 | `同步 Apple Health 数据…` | `同步 Apple Health 数据…` |
| 计算中 | `高能时长计算中…` | `入睡准备度计算中…` |

## 4. 视觉分层

不规定像素 / 字号 / 颜色（交设计决定），只定分层关系、强调轴、留白原则。

### 4.1 元素层级

| 层级 | 元素 | 角色 |
|---|---|---|
| L0 | 主数字（`7h 29min` / `82%`） | **视觉主角** —— 一眼即读，最高权重 |
| L1 | 分档 · 状态行 | 次角双元素 —— 分档定性、状态行动态解释 |
| L2 | 副标题 | 陪衬 —— 固定功能说明，不代言感受 |
| L3 | 手动切换入口 | 辅助入口 —— 视觉最轻，不抢焦点 |

### 4.2 强调轴

- **主轴 = 大小**：L0 / L1 / L2 的层级差靠字号拉开，不靠颜色对比。
- **辅轴 = 留白**：元素间距引导阅读节奏；垂直排列为主。
- **禁用**：高饱和对比色 / 强烈动效 / 图标装饰（与 [主文档 §L4](../../主文档.md) 的"冷静感"对齐）。

### 4.3 竞争元素优先级

| 竞争场景 | 谁先被看到 | 理由 |
|---|---|---|
| 主数字 vs 状态行（任意子态） | 主数字优先 | L0 > L1；状态行永不抢数字 |
| 分档 vs 状态行 | 同级，不竞争 —— 上下或左右并排即可 | 分档定性 / 状态行动态，职责互补 |
| 跨模式切换（日 ↔ 夜） vs 状态行刷新 | 模式切换优先，状态行在切换完成后再更新 | 一次只有一处动，避免视觉乱跳 |

### 4.4 留白原则

| 组合 | 留白策略 |
|---|---|
| 副标题 ↔ 主数字 | 紧凑（同组） |
| 主数字 ↔ 分档 | 紧凑（同组） |
| 分档 ↔ 状态行 | 留白一档（状态行独立） |
| 状态行 ↔ 切换入口 | 留白一档（切换入口独立） |
| Hero ↔ 下方 `event-attribution` | 留白明显（模块分区感） |

### 4.5 动静关系

- **静态层**：主数字 / 副标题 / 分档 —— 除跨模式切换外不动。
- **动态层**：状态行 —— 文案在 T1 / T2 / T3 / E 之间切换；切换**只可文字瞬切或短时淡入淡出**，禁止跑马灯 / 滚动 / 弹跳 / 闪烁。
- **一次只有一处动**：数字 skeleton 加载中时状态行不变化；状态行刷新时数字静止；跨模式切换时两者协调先后而非同时。

## 5. 交互关键帧

只描述关键时刻，不规定动效参数（ms / 曲线 / 距离）。

### 5.1 进入 Hero（首屏加载）

- **t0 挂载**：Hero 按当前模式布局；主数字位 skeleton；状态行 `同步 Apple Health 数据…`
- **t1 数据到达**：
  - 成功 → skeleton 撤除、状态行切 `{指标}计算中…`（日间 `高能时长计算中…` / 夜间 `入睡准备度计算中…`）
  - 无数据 → 主数字灰色占位、分档不显示、状态行 `Apple Health 数据未更新`
  - 失败 → 主数字错误占位、状态行 `数据同步失败 · 点击重试`
- **t2 计算完**（仅成功路径）：主数字就位；状态行按 §2.B 优先级进入 T1 / T2 / T3

### 5.2 日 ↔ 夜 模式切换

- **自动触发**：日→夜 = `now ≥ 推荐入睡时间 - 3h`；夜→日 = 夜间睡眠事件 `just_completed`
- **手动触发**：用户点击切换入口（形态交设计，文案见 §3.2）

单次切换：
- **t0**：当前模式
- **t1**：**同组变化** —— 主数字 / 副标题 / 分档 / 状态行 / 切换入口文案一起更新，给"明确进入 / 退出夜间"的感受
- **t2**：新模式稳定

**手动切换记忆**：仅本次有效；下次进入 Hero 按自动规则重新判定（见 §2.C）。

### 5.3 状态行切换

触发场景：
- 事件 `in_progress` 开始 → 切 T1
- 事件 `just_completed` → 切 T2（按距今时长逐档刷新文案）
- T2 过 3 小时 → 自动退回 T3
- T3 预测点 `{HH:MM}` 到达 → 刷新到下一曲线形态文案

单次切换：
- **t0**：旧文案
- **t1**：文字**瞬切或短时淡入淡出**；主数字 / 分档保持静止
- **t2**：新文案稳定

**刷新频率**：不低于每分钟一次（否则 T3 的 `约 {HH:MM}` 会显示过期值）。
**禁止**：跑马灯 / 滚动 / 弹跳 / 闪烁 / 颜色跳变（违反 §4.2 冷静感）。

### 5.4 点击交互

| 目标 | t0 | t1 | t2 |
|---|---|---|---|
| 日间主数字 → 下钻 `energy-detail` | 可点击态 | 轻微下沉 / 高亮反馈 | 路由到下钻模块（入场方式交设计） |
| 夜间主数字 | 不可点击态（视觉不呈现可点击 affordance） | — | — |
| 错误态状态行 → 重试 | `数据同步失败 · 点击重试` | 状态行切 `同步 Apple Health 数据…`、主数字回 skeleton | 走 §5.1 t1 / t2 路径 |
| 手动切换入口 | 入口可见 | 轻反馈 | 同 §5.2 手动分支 |

**不做**：Hero 内就地展开曲线或事件详情（曲线归 `energy-detail`，事件展开归 `event-attribution`）。

## 6. Do / Don't

| # | Do | Don't | 为什么 |
|---|---|---|---|
| 1 | 日间主数字 `7h 29min` | `450 分钟` / `剩余 Xh` / `还差 Xh` | [§L4 正面框架](../../主文档.md)：`剩` / `差` 是电量心智 |
| 2 | 日间分档 `良好` | `良好 82%` / `良好（较昨日 ↑）` | [§L4 禁差值 / 百分比](../../主文档.md)：分档是结论，不附带数字 |
| 3 | 夜间主数字 `82%` | 进度条图形 / `离入睡还差 18%` | 夜间 % 是"达到"心智，非"剩余"；禁止用进度条解释 |
| 4 | 状态行 T2 `15 分钟前完成跑步` | `15 分钟前完成 30min 跑步 · 高能 +15min` | §3.3 去重约束：duration / impact 由下方事件卡片承担，Hero 不重复 |
| 5 | 状态行 T3 `进入上升期，约 10:20 见顶` | `因为睡得好所以上午会高能` / `今天要特别珍惜` | [§L4 禁因果断言 / 情绪代言](../../主文档.md)：因果归 Agent 对话 |
| 6 | 状态行 `身体急需休息，建议入睡` | `该睡觉了 · 立即开启勿扰模式` | Hero 不做行动指挥；具体操作归事件卡片的 Ask Isho 入口 |
| 7 | 副标题 `今日头脑清晰时长`（固定文案） | `昨晚睡得真棒，今天能量满满` | 副标题是功能说明，不代言用户感受；不随数据变化 |
| 8 | 状态行动效：文字瞬切或短淡入淡出 | 跑马灯 / 滚动 / 闪烁 / 弹跳 | §4.5 一次只有一处动；冷静感 |
