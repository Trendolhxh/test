# 入睡准备度计算 · MVP 算法

> 本文档是入睡准备度服务 v1 MVP 的**计算逻辑直接定义**——研发可据此实现。目标：先跑通、在真实数据上验证体感准确度，再决定是否升级到完整两轴模型（见 [开发文档](./开发文档.md) §2）。

---

## 1. 简化决策

相对开发文档里提到的完整"两轴 × 多子分"模型（Body: f_S × f_C × f_W 乘法核 + Environment 加权求和），MVP 砍到最简：

- **只算 Body Readiness 单轴**；Environment 先不做（`env_readiness_value` 返回 `null`）
- **只用 3 个生理因子**：清醒时长 / 心率 delta / HRV delta
- **三者加法（等权平均）**；不做乘法核、不做瓶颈钳制
- **不做 f_S / f_C / f_W 子分**；因子扁平加和

---

## 2. 总公式

```
readiness_value = round( (score_wake + score_HR + score_HRV) / 3 )
```

每个因子独立计算，返回 `[0, 100]` 整数；平均后取整为最终输出。

---

## 3. 因子 1 · 清醒时长（score_wake）

### 输入
- `T_wake`（小时） = `now − day_start_at`
- `day_start_at` 来自 [shared/一日窗口.md](../../shared/一日窗口.md)（上一次 `night_sleep.end_at`；无数据则兜底本地 05:00）

### 映射
| `T_wake` | `score_wake` |
|---|---|
| `≤ 0` | 0（异常情况兜底） |
| `0 – 17h` | `T_wake / 17 × 100`（线性爬升） |
| `> 17h` | `100` |

> MVP 暂不扣"过度疲劳"（如清醒 > 20h 倒扣分）。

---

## 4. 因子 2 · 心率 delta（score_HR · 双向偏移）

### 输入
- `HR_now`（bpm） = 当前心率；取最近 5 分钟平均值
- `HR_rest`（bpm） = 个人静息心率基线；取过去 14 日静息心率均值

### 计算
```
ΔHR = HR_now − HR_rest
|ΔHR| = abs(ΔHR)     // 取绝对值，偏高或偏低都计入偏移
```

### 映射
| `|ΔHR|` | `score_HR` |
|---|---|
| `≤ 10 bpm` | `100`（在基线附近 ± 10 内即满分） |
| `10 – 30 bpm` | `100 − (|ΔHR| − 10) × 5`（线性下降，`|ΔHR| = 20` 时得 50） |
| `≥ 30 bpm` | `0` |

> 双向偏移的意义：HR 明显高于基线（交感激活）或明显低于基线（异常低心率）都视为偏离入睡理想区间。

---

## 5. 因子 3 · HRV delta（score_HRV · 单向偏移）

### 输入
- `HRV_now`（ms） = 当前 HRV（RMSSD），取最近可用静息采样值
- `HRV_baseline`（ms） = 个人 HRV 基线；取过去 14 日夜间静息 HRV 均值

### 计算
```
ΔHRV = HRV_now − HRV_baseline
```

### 映射
| `ΔHRV` | `score_HRV` |
|---|---|
| `≥ 0` | `100`（已达或超过基线；HRV 偏高为正向信号，不扣分） |
| `-20ms – 0` | `100 + ΔHRV × 5`（线性下降） |
| `≤ -20ms` | `0` |

> 单向偏移：HRV 低于基线（副交感抑制 / 应激状态）扣分；HRV 高于基线视为放松状态，不扣分。

---

## 6. 分档映射（bucket）

`readiness_value` → 4 档文字：

| 区间 | bucket |
|---|---|
| `0 – 30` | `身体仍活跃` |
| `31 – 55` | `正在放松` |
| `56 – 85` | `已进入放松` |
| `86 – 100` | `身体急需休息` |

> 区间边界是 MVP 首版预估；PM 在实际数据上看分布后调整。

---

## 7. 因子缺失降级

| 缺失项 | 降级 |
|---|---|
| HRV 不可用 | `readiness_value = (score_wake + score_HR) / 2` |
| HR 不可用 | `readiness_value = (score_wake + score_HRV) / 2` |
| 清醒时长不可用（极罕见） | `readiness_value = (score_HR + score_HRV) / 2` |
| 只剩 1 个因子可用 | 直接取该因子的子分 |
| 3 个全部缺失 | `status = failed`；hero 走空数据态 |

---

## 8. 冷启动 / 无基线

新用户前 14 天无个人基线：

| 因子 | 兜底参数 |
|---|---|
| `HR_rest` | 60 bpm（群体先验，后续可按性别 / 年龄分档优化） |
| `HRV_baseline` | 40 ms（群体先验） |

> 兜底参数写入配置表，便于后续按实际用户分布调整，不写死在代码里。

---

## 9. 非 MVP 范围（v2 升级路径）

待 MVP 在真实数据上验证后再考虑：
- 恢复 `f_S × f_C × f_W` 三子分乘法核结构
- 加入 DPG（远端皮温趋势）、昼夜相位估计
- 加入过度疲劳反向扣分（清醒时长 > 阈值）
- 加入 Environment Readiness 第二轴
- 个人基线的贝叶斯更新机制
