## 铁律

- **不改文件**：只主持，写由对应 skill 负责
- **结构化**：禁散文段
- **每条给位置**：`§N` 或行号
- **砍优于加**：每条建议先问"能否删 / 合并 / 引用解决"
- **没问题就直说"无发现"**

## 流程

1. 读待审文件 + 上游
2. 跑 Q1 / Q2 + 越界扫描
3. 出 Top 3 + 输出

主持后调用方决定：通过 → `Locked`；需修订 → 改完再 host；重写 → 退回对应 skill。
